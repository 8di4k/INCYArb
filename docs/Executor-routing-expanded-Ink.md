# Расширенный поиск через исполнителей и агрегаторы Ink

22 октября 2026 UTC. В этой ограниченной выборке новая доступная оракульная
сторона **не подтверждена**. Наблюдаемые маршруты расширяют карту AMM и
агрегаторных обёрток; известный xChange остаётся отдельным RFQ с допуском.
Это не основание включать pool-only стратегию в production.

Статус относится к вызову контракта: среди них есть служебные операции.
Окна различаются и ограничены 100 записями; таблица не ранжирует ботов по

В трассах встречаются Uniswap v3/v4, Velodrome v2 и CL-пулы. Вспомогательные
контракты распределения выручки, airdrop, buyback и fee accounting не являются
самостоятельными площадками обмена. Пять наблюдаемых v4 hooks включают Aegis,
QuotronStockHook, MasterLaunchHook и два ранее учтённых неизвестных hook;
их присутствие не доказывает внешний ценовой оракул.

Вызовы `DynamicSwapFeeHook`
`0xc0ed888afe87ed1acf01d9f19bb850159e3ce434` и его опубликованный исходник
показывают вычисление комиссии с параметром caller, pool tick/TWAP и
MEV-компонентом. Это оракул состояния пула для комиссии, а не найденный
внешний oracle-priced stock venue. Условия конкретного исполнителя нельзя
автоматически переносить на наш контракт. `CLPoolTape`
`0x27d5eb73e7406675f6b0cbd037490ec3dba935a4` также относится к инфраструктуре
CL-пула. Метаданные explorer не заменяют независимой проверки сборки и
исторического runtime для всех этих адресов.

## Что находится внутри CoW и 0x

Декодированы 50 входящих CoW settlements за **05:01:48–21:48:57 UTC**,
173 interactions. Пагинация имеет продолжение: это не все settlements дня.

- 37 interactions вызывают 0x AllowanceHolder
  `0x0000000000001ff3684f28c67538d4d072c22734`, затем InkSettler
  `0x2790b7bfbcdcd2d5662885225ed1633b305cbc63`.
- 6 interactions вызывают уже найденную xChange-интеграцию
  `0x9fc428fde25c5c062c2c9cce0be18a1fbec45a42`. Это известный адрес,
  не шесть независимо проверенных прибыльных арбитражных кругов.
- Дополнительные обёртки проверены пятью call traces: видны CL/v4 маршруты,
  новая RFQ-сторона не установлена.

Отдельно декодированы 50 прямых входящих вызовов AllowanceHolder за
**20:42:58–22:05:12 UTC**: 45 направлены в InkSettler, 5 — в InkBridgeSettler
`0x9c3eda79bc6ab8fb735f18107f45afe72316dd57`.
Пересечения transaction hashes между этими двумя страницами по 50 нет.
Оба окна ограничены одной страницей; их нельзя экстраполировать на весь поток.

Действия — не количество сделок. BASIC дополнительно распакован: присутствуют
вызовы Velodrome/Uniswap routers, wrap/unwrap, token transfers и выплаты
native currency. Название VIP у v4-действия не означает RFQ.
Селекторы RFQ `0xd92aadfb` и RFQ_VIP `0x604ba49a` в этих двух наборах
InkSettler actions не обнаружены. Это ограниченный результат декодирования,
не утверждение об отсутствии RFQ во всех вызовах 0x или о природе всех hooks.

В пяти bridge-вызовах найдены BASIC, SETTLER_SWAP и Across bridge actions.
Вложенные SETTLER_SWAP здесь не квалифицированы как отдельные venues;
межсетевой перевод сам по себе не закрывает атомарный круг внутри Ink.

## Проверка и сохранённые данные

[Архив](validation/competitor-traces/expanded-routing.json.gz), SHA-256
`4363995793450caa9687d9412324546402988b7623726a5368a89fee14fc449e`,
содержит 500 index records, 31 executor trace, две страницы по 50 записей,
декодированные действия, пять дополнительных CoW traces и два RPC rechecks.
Источники — публичные Ink Blockscout API v2 и RPC
`https://rpc-gel.inkonchain.com`. Это explorer traces, не собственный EVM replay.

Для всех 31 executor trace проверено совпадение root from/to/input с
index metadata. Для forwarding `exec(address,address,uint256,address,bytes)`
и вложенных execute проверено обратное ABI-кодирование канонической части;
исходная calldata сохранена целиком, включая возможный дополнительный suffix.
Неуспешные поддеревья не считаются фактически выполненными переводами.

Дополнительно через RPC перечитаны receipt и canonical block hash для
успешной `0x66fc701bd2ae0a0531e5f4774da8c1b2714cd5007a61fb0cef89fde95767e1e4`
и неуспешной `0x9120b5f74b4c9d534a81b04ae8faf81bf9313dc13966a5c0e53d6dd031bdbc95`.
Статус и сумма `gasUsed * effectiveGasPrice + l1Fee` совпали с explorer:
соответственно **467597546250** и **32116383495 wei ETH**.
Остальные 498 статусов/комиссий в этом проходе получены из explorer index.
Стоимость ETH и полная периодная прибыль исполнителей не устанавливались.

Архив сохраняет ABI, имена, compiler metadata и SHA-256 опубликованных
исходников, без их текстов. В частности, исходники с
`LicenseRef-Dromos-Restricted-Use-1.0` не перепубликуются.

Следующий полезный seed — новый неизвестный коммерческий контрагент внутри
замкнутого token flow, с одним или без стандартных Swap events. Для допуска
к стратегии нужны его фактические access/fee checks, свежие котировки и
проверенный полный круг от нашего исполнителя. Известные AMM wrappers,
bridge flows и отложенный xChange onboarding повторно за новые кандидаты
не считаются.
