# Base: сетевой перебор полных flash-симуляций

**Проверены 547 вариантов транзакции через публичный Base RPC. Найдены два
раздельных положительных состояния в сплошном диапазоне. Лучший проверенный
вариант при tip 0,001 gwei оставляет около 0,000005358 ETH после сетевого
бюджета — примерно $0,013 по цене того же снимка.** Это результат `eth_call`,
не заработанная отправленной транзакцией прибыль.

Продолжение [полного flash-funded replay](Flash-funded-oracle-proof-Base.md).
Времена ниже — **23 октября 2026, Москва (UTC+3)**. Исследуется Base;
пригодная публичная оракульная сторона на Ink по-прежнему не квалифицирована.

## Что именно перебирали

Biconomy onchain `getPairs()` объявляет WETH/USDC, USDC/cbBTC и WETH/cbBTC.
Проверены оба стартовых актива каждой пары, оба порядка площадок и размеры
примерно от $1 до $1000. Размеры WETH/cbBTC определяются котировкой
USDC → соответствующий актив на том же блоке, а не фиксированной долларовой
ценой. Дополнительно проверены границы объёма из onchain maker board.

Каждый вариант — один полный вызов:
**v4 unlock/take → два обмена → sync/repay/settle → выплата**.
Для старта не в WETH диагностический контракт дополнительно меняет прибыль
в WETH после погашения; стоимость этой конвертации входит в результат и газ.
Поэтому её нельзя считать бесплатной оценкой прибыли в другом токене.

Доступен специальный более дешёвый путь WETH → Biconomy direct fill →
USDC → Elfomo → WETH. Его сравнивали отдельно с обобщённым исполнителем.
Оба начинают без торгового капитала; overrides меняют только код синтетического
исполнителя и ETH-баланс отправителя для оплаты газа. Market/token/PoolManager
state, allowance площадок и maker limits не подменяются.

Прогоны включают отдельные повторы с бюджетным gas limit и EIP-1559 caps.
L2 считается по лимиту с запасом 20%, L1 — через `getL1FeeUpperBound` для
конкретного unsigned envelope; operator fee читается отдельно.
Неизвестные обязательные расходы не превращаются в нулевые.

Сумма 547 включает повторные варианты на выбранном состоянии и не является
числом разных возможностей. Разные объёмы, fee caps и проверки одного блока
не складываются в отдельные заработки.

Сплошной диапазон **52962803–52962930**, **03:22:33–03:26:47**, выбран до
чтения котировок внутри него. Оба направления проверены на каждом блоке;
для обоих повторно сверены все 128 hash и ancestry.

Положительные состояния прямого направления:

| Блок | Время | Заём WETH | Остаток после бюджета, ETH |
| --- | --- | ---: | ---: |
| 52962834 | 03:23:35 | 0,06335 | +0,000005358321005626 |
| 52962853 | 03:24:13 | 0,06335 | +0,000002447187385323 |

Они разделены **19 блоками / 38 секундами**. Каждый вызов начинает с исходного
состояния сети; наши предыдущие fills между блоками не переносятся. Это
повторное появление положительного расчёта, а не доказательство возможности
получить оба результата собственными последовательными сделками.

В первом срезе maker liquidity есть только на WETH/USDC. По обоим направлениям
двух cbBTC-пар boards пусты/remaining = 0, хотя пары объявлены каталогом.
Полные пробы сохраняют реальные откаты. Заявленный список пар сам по себе
не означает доступной глубины.

## Лучший проверенный защищённый круг

На блоке **52962834**:

| Компонент | Значение |
| --- | ---: |
| Заём и возврат | 0,06335 WETH |
| Порядок | Biconomy direct fill → Elfomo |
| Фактический остаток после возврата и до газа | 0,000009361062181852 WETH |
| Onchain minimumProfit | 0,000006 WETH |
| Gas estimate с этим порогом и выплатой | 555 864 |
| Gas limit с запасом 20% | 667 037 |
| Полный сетевой бюджет | 0,000004003179176226 ETH |
| **Остаток после бюджета** | **+0,000005357883005626 ETH** |

`minimumProfit` превышает рассчитанный сетевой бюджет; круг с ним прошёл.
Порог 0,00001 WETH уже отклонён фактическим `InsufficientProfit`.
Gas limit/fee caps также проверены повторным вызовом, token output совпал.
Порог защищает gross в токене; будущие расходы и включение всё ещё требуют
отдельной проверки.

USD-ориентир взят из первой WETH/USDC цены maker board того же блока:
**2383,529834 USDC/WETH**. Получается около **0,01277 USDC**. Выплата остаётся
WETH; это пересчёт стоимости, а не выполненная выплата USD-стейбла.

## Что ограничивает улучшение

Лучший объём среди проверенных — фактический maker cap **0,06335 WETH**.
Проверены 11 размеров от 1% до 100% лимита. При 25% лимита расходы ещё выше
прибыли; при 50% расчёт уже положителен. При добавлении **1 wei** сверх лимита
или удвоении объёма Biconomy откатывает исполнение. Больший доступный баланс
flash-источника этот лимит не снимает.

Для полного лимита без дополнительного profit floor получены:

| Tip, gwei | Остаток после бюджета, ETH |
| --- | ---: |
| 0 | +0,000006052241867000 |
| 0,001 | +0,000005358321005626 |
| 0,003 | +0,000004066633005626 |
| 0,01 | −0,000000565154994374 |

Нулевая ставка показывает условную экономику, но не подтверждает включение.
При 0,01 gwei прибыль уже исчезает. Ограничения комиссий и maker доступа могут
меняться; текущий успех синтетического caller не удостоверяет будущие условия.

## Воспроизведение и границы вывода

```bash
python scripts/search_flash_pairs.py --solc /path/to/solc-0.8.28 \
  --block-number 52962834 --output data/base-flash-matrix.json.gz
```

Без `--block-number` берётся свежий `head - 2`. Скрипт читает каталог и boards,
перебирает разрешённые три актива, выбирает активных makers и сравнивает
объёмы/порядок площадок. При нескольких активных makers отдельно проверяется
и общий venue. Исследование ограничено 512 вариантами за запуск. Это поиск
среди заданных площадок и размеров, не доказанный глобальный максимум рынка.

[Manifest](validation/fresh-oracle-search/manifest.json) связывает собственный
[обобщённый контракт](validation/fresh-oracle-search/FlashPairSearch.sol),
его зависимость из предыдущего исследования, raw calls, compiler-bound runtimes,
каталоги/boards, полные диапазоны и уточнение выбранного кандидата. Offline
пересчёт всех оценённых строк совпадает с архивом. RPC — `mainnet.base.org`;
независимое локальное исполнение venues и их компиляция не проводились.

Источник расхождения именно в задержке двух оракульных публикаций не установлен.
Состояние конца блока не гарантирует доступность той же сделки при включении
следующей транзакции. Не измерены собственное влияние между блоками, получение
приоритета, все неудачные реальные попытки, deployment и обслуживание.
Поэтому регулярный доступный доход от $100/сутки и live-запуск пока не
квалифицированы. Число конкурентов не является самостоятельным ограничением.
