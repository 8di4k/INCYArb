# Оракульная сторона стратегии на Ink

Срез: 22 октября 2026 UTC. Котировки и состояние ниже относятся к указанным
блокам, а не обещают доступность в будущем.

## Цель и критерий пригодности

Рабочая стратегия X Layer, описанная владельцем: взять USD₮0 через v4 unlock,
при необходимости обменять на USDG, купить/продать xStocks через BinaryFi или
Caliber против v3 либо второй оракульной площадки, погасить дельты и проверить
минимальную прибыль. Источник преимущества — расхождение обновляемой внешней
цены и рынка. Круги только через AMM были отключены из-за убытков и не являются
целевой стратегией переноса.

Нужны одновременно: подтверждённые адреса токенов и площадки, доступ именно
нашему исполнителю, актуальная модель цены/комиссий/лимитов, ликвидность и
синхронная передача токенов внутри одной транзакции. Затем — pinned EVM-проверка
полного круга и net после расходов, включая неудачные попытки и конкуренцию.
Существующие модели AMM и replay пригодятся как вторая сторона и средство
проверки, но сами по себе не подтверждают перенос доходности.

## Kaliber: deployment найден, рабочая сторона пока отсутствует

Адрес Ink `0xf639cf213b63f7e77d699ff686d591c0ba55fc63` найден в
[адаптере DefiLlama](https://github.com/DefiLlama/dimension-adapters/blob/5710ba6f10002d89bdf6c5698e5d7c9d50e4d1d9/dexs/aptos-caliber-prop-amm/index.ts).
Для чтения использован [ABI Kyber](https://github.com/KyberNetwork/kyberswap-dex-lib/blob/b450e6ddc421104cafc4facd686ea55d1b0b7139/pkg/liquidity-source/caliberprop/abi/Caliber.json).

[Архив RPC-проверки](validation/kaliber-ink-59205232.json):

- Chain ID: `57073`; блок `59205232`, hash
  `0x771ac7eeb4305acb266b0ef633d5ee2b73e95d4f1c31b56a6d793001aa8e4c3e`.
- Runtime: 22 042 байта, keccak
  `0xffbc0e738b4d4d5275d847a6949a49e1c3de31769cc0fcea4e4a6541752eba41`.
- Полная выдача `getAllPairIds`: одна пара; точный `keccak(base||quote)`
  соответствует WETH `0x4200000000000000000000000000000000000006` и native
  USDC `0x2d270e6886d130d724215a266106e6832161eaed` (не USDC.e).
- `getPoolBalances`: `40001000000000000` wei WETH и `50100000` raw USDC,
  то есть 0,040001 WETH и 50,1 USDC.
- Два размера в каждом направлении (0,1% и 1% входного резерва): четыре
  revert, код RPC 3, данные `0x2af96ae8`. Селектор совпадает с прежним
  stale-price кодом Caliber в исследовании Arbitr; семантика нового runtime
  независимо не доказана. Доступной положительной котировки нет.
- xStocks-пар в этом экземпляре на этом блоке нет. Это не доказывает отсутствие
  других deployments или оракульных площадок во всей сети.

Команда `oracle-venue-snapshot` повторяет перечисление, чтение балансов и
пробы. Она проверяет chain ID и неизменность hash блока. Адреса пары определяются
только точным совпадением хэша среди известных inventory-токенов; неизвестные
ID не отбрасываются. Metadata и символы не удостоверяют эмитента.
Размер страницы и лимит страниц ограничены; неполная выдача помечается явно.
Ошибки RPC, нулевые котировки и revert различаются; даже положительный quote
оставляет `strategy_status: unconfirmed`, `execution_verified: false`.

## xStocks и новая кандидатура xChange

[Официальный публичный API эмитента SPYx](https://api.xstocks.fi/api/v2/public/assets/SPYx)
подтверждает на Ink SPYx `0x90a2a4c76b5d8c0bc892a69ea28aa775a8f2dd48`,
wrapper V2 `0xe7e553cd128f0011777323a0b44a7b96ea1cb540` и
`supportsAtomicSwaps: true` с native USDC.
[Ответ сохранён](validation/xstocks-SPYx-2026-10-22.json).

Согласно [руководству xChange](https://docs.xstocks.fi/developers/xchange-atomic-rfq),
Ink поддерживается, обмен выполняется EVM-вызовом `executeSwap` с EIP-712
авторизацией. Котировка задаёт обе передачи, адреса и срок действия;
предварительный allowance позволяет обойтись без permit-подписи токена.
Это RFQ-кандидат, а не подтверждённый аналог публичного Caliber.

Доступ требует клиентского API key и зарегистрированных кошельков; первичный
рынок требует [onboarding и whitelist](https://docs.xstocks.fi/docs/issuance-and-redemption).
Конкретный deployment и исполненный обмен с контрактом теперь
[найдены через реальную транзакцию](Xchange-observed-Ink.md).
Допуск нашего контракта, spread/лимиты и полный flash-funded круг не проверены.
Приватные RFQ не запрашивались; аккаунты и сделки не создавались.

Следующая проверка для этой кандидатуры: допуск нашего payment/receiving адреса,
возможность получить разрешённую котировку, wrap/unwrap и точные расходы против доступных AMM.
Без этого добавлять исполнительный адаптер преждевременно.

## Решение по реализации

Продолжение поиска: [1 474 актива эмитента, 1 836 пулов и 38 hook-адресов](Xstock-hook-search-Ink.md).
В доступных исходниках найдены комиссии, launch и TWAP/TWAMM-механика; 20 адресов
остаются неразобранными. Пригодный публичный оракульный контрагент пока не
подтверждён. xChange оставлен на будущее по решению владельца.

Продолжать поиск и квалификацию оракульной/RFQ стороны; не строить live-торговлю
на найденном неработающем Kaliber и не подменять цель AMM-only маршрутом.
После подтверждения доступа и экономики — адаптер и полная EVM-проверка,
затем обновление моделей из stream без RPC в горячем поиске. Исходные
latency и доходность X Layer не переносятся на Ink автоматически.
